This is the source code for select pages on my personal website, NEOPETS.LGBT, nothing more nothing less.<br>
Originally a Neocities page in 2017, left Neocities and became NEOPETS.LGBT in 2020, project added to GitHub in late 2024.<br><br>
I added NEOPETS.LGBT to GitHub for transparency:

1. Because I usually update the site right after I make a new commit, this is basically the site's changelog now.
2. I made it easier for you to take my code and use it for your passion project by putting it here!
3. We need more fun and helpful websites, HTML playgrounds.
4. Get creative with HTML/CSS for your personal site. JS is rarely used on mine; disabling it will not break NEOPETS.LGBT.
5. Hop off landing pages like linktree that all look the same, for-profit website builders like squarespace that squeeze your wallet for something you could do yourself at a fraction of the cost, and hop on https://straw.page or https://neocities.org if you're a beginner in coding and interested in the thrill of taking more control over your online presence.
